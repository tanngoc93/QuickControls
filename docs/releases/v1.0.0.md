Quick Controls 1.0.0 is the first public release of the Windows volume and brightness utility for keyboards without media keys.

## Recommended download

Download **QuickControls-Setup.exe**, open it, and select **Install now**. The per-user installer creates Desktop and Start menu shortcuts and does not request administrator access.

Use **QuickControls-Portable.zip** only when you prefer to extract and run the app without installation.

## Included features

- Six customizable global shortcuts for volume, brightness, mute, and panel visibility.
- Expanded and compact floating control panels.
- Windows master volume and mute control.
- Laptop brightness through WMI.
- Compatible external monitor brightness through DDC/CI.
- Multiple-display selection, system tray controls, startup with Windows, and local settings.

## Verify the download

`SHA256SUMS.txt` contains the SHA-256 digest for both downloadable packages.

## Windows security notice

These binaries are not currently signed with a commercial code-signing certificate. Windows SmartScreen may display a publisher warning. Only continue when the file was downloaded from this official release. A managed computer can block unsigned software through Application Control; follow the organization's security policy instead of attempting to bypass it.
